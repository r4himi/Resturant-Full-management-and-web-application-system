# BigBurgers

A Django-based restaurant ordering system where customers can browse the menu, add items to a cart, and place orders online.

## Features

* User authentication
* Menu categories
* Add items to cart
* Quantity controls
* Order placement
* Order history
* Admin item management
* Responsive UI

## Tech Stack

* Python
* Django
* HTML
* CSS
* JavaScript
* SQLite

## Installation

1. Clone the repository

```bash
git clone https://github.com/r4himi/Resturant-Full-management-and-web-application-system.git
cd Resturant-Full-management-and-web-application-system
```

2. Create and activate a virtual environment

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

Linux/macOS:

```bash
source venv/bin/activate
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Apply migrations

```bash
python manage.py migrate
```

5. Run the server

```bash
python manage.py runserver
```
